# 《跨次元大亂鬥 3D (Dimension Clash Online 3D)》

> **3D 橫向/全向動作格鬥 / 大亂鬥跨平台網頁遊戲**  
> 跨宇宙經典陣容（七龍珠、漫威、機動戰士鋼彈），支援 **第一人稱**、**第三人稱**、**上方俯瞰視角** 切換，**360 度四面八方全向走位與 3D 跳躍**、1v1 ~ 5v5 KOF 式輪替淘汰賽、機體改裝配件、Level 1~100 深度養成、九大稀有度階梯！

---

## 🎮 快速遊玩與部署 (Deployment)

本專案採用純前端靜態 3D 架構（Three.js WebGL 3D + Web Audio API + WebRTC P2P），**零外部依賴、零伺服器維護成本**，可直接部署於 **GitHub Pages** 或 **Vercel**。

### 📦 部署至 GitHub Pages：
1. 將本專案 Push 至 GitHub 倉庫的 `main` 分支。
2. 進入倉庫的 **Settings** -> **Pages**。
3. 在 **Branch** 選擇 `main` / `/ (root)` 並點擊 **Save**。
4. 約 1 分鐘後即可透過 `https://<你的帳號>.github.io/<倉庫名稱>/` 直接在電腦與手機瀏覽器上體驗全 3D 跨次元對決！

## 🌟 核心 3D 特色與系統架構

### 1. 🎥 三大多視角切換系統 (Camera Perspectives)
- **第一人稱視角 (First-Person View, 1st Person)**：置身於角色視線高度，享受沉浸式近身肉搏與光束氣功瞄準！
- **第三人稱跟隨視角 (Third-Person View, 3rd Person)**：動態背後跟隨與自動鎖定敵方，支援滑鼠 / 觸控 360 度環繞觀看。
- **上方俯瞰視角 (Top-Down / Tactical View)**：高空鳥瞰擂台全景，掌控全場戰局與雙方站位。
- **快速切換**：PC 按 `V` 鍵 或 點擊右上角「🎥 視角切換」按鈕即可瞬間循環切換！

---

### 2. 🕹️ 四面八方 360 度走位與 3D 滯空跳躍 (3D Omnidirectional Movement)
- **八向 / 360 度全向走位**：PC 使用 `W/A/S/D` 鍵，手機使用左側 360° 虛擬搖桿，無死角前後左右滑行與突進。
- **3D 跳躍與空中二段跳**：`Space` 空白鍵觸發跳躍與空中二段跳，可進行空中下砸與滯空追擊。
- **3D 閃避翻滾 (Dodge Roll)**：`Shift` 鍵觸發 0.3 秒無敵幀位移。

### 4. 3D KOF 式輪替淘汰賽 (1v1 ~ 5v5)
- **勝者留場**：獲勝方角色保留殘餘血量與累積怒氣，短暫無敵 2 秒後迎戰下一位登場對手。
- **登場保護**：陣亡方下一順位角色滿血降臨並享有 2 秒無敵保護力場。
- **一挑多雙倍金幣**：首發角色達成單人 1 穿 3 或 1 穿 5 結算時獲得雙倍獎勵！

---

### 5. 機體改裝與 4 插槽裝備系統
- **插槽 1：動力核心**：原裝 GN 爐、米諾夫斯基熱核反應爐、雙重亞哈反應爐、宇宙魔方能量電池、超重力界王負重手環。
- **插槽 2：武裝背包**：超級龍騎兵浮游系統、雙聯裝光束加農砲、光之翼推進背包、奈米修復注入器、特製仙豆腰包。
- **插槽 3：防禦裝甲**：I-Field 能量防護發生器、相轉移裝甲 (PS Armor)、奈米積層裝甲、振金編織內襯、波特拉耳環。
- **插槽 4：戰術晶片**：ZERO 系統 (預判大招紅光警報)、NT-D 破壞者系統 (<40%血暴走)、阿賴耶識系統 (破甲脆弱)。

## 🕹️ 3D 戰鬥操作對照表

| 動作種類 | PC 鍵盤 / 滑鼠操作 | 手機觸控操作 | 動作效果說明 |
| :--- | :--- | :--- | :--- |
| **3D 視角切換** | **V 鍵** | **頂部「🎥 視角切換」** | **第三人稱 ⇄ 第一人稱 ⇄ 上方俯瞰** 循環切換 |
| **四面八方走位** | **W / S / A / D 鍵** | **左側 360° 虛擬搖桿** | 360 度自由全向移動 |
| **3D 跳躍 / 二段跳** | **Space 空白鍵** | **右側「跳躍」按鈕** | 空中跳躍、二段跳與滯空打擊 |
| **3D 防禦 / 翻滾** | S (格擋) / Shift (閃避) | 「盾防 / 翻滾」 | 3D 格擋減免 80% 傷害；翻滾具無敵幀 |

| **戰術小招 1** | U 鍵 | 「技能 1」按鈕 | 短 CD (2~4s) 3D 突進或射擊 |
