## 🌟 核心 3D 特色與最新升級

### 1. ✈️ 飛行角色專屬起飛鍵 `[F]` (Flight & Hover Mechanics)
- 具備飛行設定之角色（鋼鐵人、索爾、緋紅女巫、奇異博士、滅霸、攻擊自由、能天使、飛翼 Zero、賽亞人超賽悟空、貝吉塔、比魯斯等）可按 **`F` 鍵** 或點擊 **「飛行[F]」** 進入 3D 空中懸浮飛行狀態！
- 飛行狀態下可進行 360 度無重力空中制空打擊、光束轟炸與高空突進。

---

### 2. 🛡️ 嚴格成就與創世解鎖驗證 (Strict Achievement Verifier)
- 杜絕隨意領取！所有創世/概念級神級角色必須在遊戲中達成真實目標數據才能解鎖：
  - **滅霸 (六石手套)**：PVE 極限「無限之戰」一命無傷通關 10 層魔王塔。
  - **自在極意功 悟空**：PVP 天梯 150 勝場 且 達到 2,500 宗師獎盃。
  - **獨角獸鋼彈 (神化結晶)**：收集 15 顆感應骨架結晶。
  - **吉連 (全力量暴走)**：5v5 模式首發角色達成「1 穿 5 完封紀錄」。
  - **破壞神 比魯斯**：通關次元魔王塔全部 10 層挑戰。
  - **量子之神 征服者康**：累計造成 5,000,000 點總戰鬥傷害。
- 商店與成就面板即時顯示真實進度條與完成百分比，未達標無法領取！

---

### 3. 🎯 每個角色專屬攻擊配置與差異化招式 (Unique Character Action Profiles)
- 45 位角色皆配置專屬攻擊動作與招式名稱，切換角色時右下角觸控按鍵與提示即時切換：
  - **鋼彈機體**：[J] 光束軍刀連斬 / [K] 光束步槍狙擊破防 / [O] 盾牌撞摔 / [F] 推進器升空
  - **龍珠戰士**：[J] 龜派體術連續拳 / [K] 氣合重破 / [O] 瞬移重摔 / [F] 舞空術飛行
  - **美國隊長**：[J] 振金盾牌格鬥 / [K] 盾牌迴旋投擲 / [O] 特工擒拿抱摔
  - **蜘蛛人**：[J] 蛛絲體術連打 / [K] 高壓蛛網纏繞 / [O] 蛛絲風車甩投
  - **浩克**：[J] 泰坦重拳連轟 / [K] 浩克砸地衝擊 / [O] 狂暴抓摔狂砸 (Hulk Smash)
  - **雷神索爾**：[J] 雷神之錘重砸 / [K] 召喚九界天雷 / [O] 雷神之握重摔 / [F] 飛錘引力飛行

---

### 4. ⚔️ 開局與換人 Enter 確認流 (Enter Battle Flow)
- 進入對決前，定格展示首發角色專屬指令說明，按 **`Enter` 鍵**（或點擊確認）開始戰鬥。
- 角色倒下時暫停，按 **`Enter` 鍵** 派遣下一位隊友登場並享有 2 秒無敵護盾！

## 🕹️ 專屬 3D 戰鬥操作對照表

| 動作種類 | PC 鍵盤操作 | 手機觸控操作 | 動作效果說明 |
| :--- | :--- | :--- | :--- |
| **開始對決 / 換人** | **Enter 鍵** | **中央確認按鈕** | 開局前確認開戰 / 陣亡換人時派遣下一位英雄登場 |
| **四面八方走位** | **W / S / A / D 鍵** | **左側 360° 虛擬搖桿** | 360 度與八向自由立體移動 |
| **飛行起飛 / 舞空術** | **F 鍵** | **「飛行[F]」按鈕** | 飛行角色專屬：升空懸浮，支援空中 360 度全向制空飛行 |
| **3D 視角切換** | **V 鍵** | **頂部「🎥 視角切換」** | 第三人稱 ⇄ 第一人稱 ⇄ 上方俯瞰 循環切換 |
| **普通攻擊 (輕擊)** | **J 鍵** | **「普攻[J]」按鈕** | 角色專屬 3~4 段連續體術打擊 (磁性貼身追擊) |
| **蓄力破防重擊** | **K 鍵** | **「破防[K]」按鈕** | 角色專屬蓄力破防，強制擊碎對手格擋 |
| **摔投 / 抓技** | **O 鍵** | **「抓技[O]」按鈕** | 無視格擋，近身抓起對手重摔 |
| **戰術小招 1** | **U 鍵** | **「技1[U]」按鈕** | 短 CD (2~4s) 專屬突進或遠程牽制 |
| **戰術小招 2** | **I 鍵** | **「技2[I]」按鈕** | 短 CD (5~8s) 專屬擊飛或防守反擊 |
| **終極奧義大招** | **L 鍵** | **「奧義[L]」金色按鈕** | 需蓄滿 100% 怒氣，全螢幕特寫高額傷害 |
| **3D 跳躍 / 二段跳** | **Space 空白鍵** | **「跳躍」按鈕** | 垂直起跳、空中二段跳與滯空操作 |
| **3D 防禦 / 翻滾** | **S (格擋) / Shift (閃避)** | **「格擋 / 閃避」** | 格擋減免 80% 傷害；翻滾具 0.3s 無敵幀 |
| **備戰援護攻擊** | **Q 或 E 鍵** | **「援護[Q]」按鈕** | CD 20s，下一位隊友衝入戰場協同攻擊 |
| **極限爆發脫身** | **B 鍵** | **「爆發[B]」紫色按鈕** | 50% 怒氣，釋放立體衝擊波防止被連招 |
